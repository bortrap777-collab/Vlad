# W Studio

Мобильный редактор фото и видео. Версия 0.4.0 — **этап 4 из 5**.

## Установить на телефон

Приложение: **https://bortrap777-collab.github.io/Vlad/**

- iPhone: откройте адрес в **Safari** → «Поделиться» → «На экран „Домой“».
- Android: откройте в **Chrome** → меню ⋮ → «Установить приложение».

Обновляется автоматически при каждом изменении ветки `main` (GitHub Actions → Pages).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173 и адрес в локальной сети для телефона
npm run build      # проверка типов + сборка в dist/
npm run preview    # просмотр собранной версии
```

Без доступа к npm (как в облачной песочнице Claude) есть резервная сборка через esbuild:
`node scripts/build-local.mjs` → `dist/`, `node scripts/build-local.mjs --single` → один HTML-файл.

## Установка на iPhone как приложение

1. Выложить папку `dist/` на HTTPS-хостинг (GitHub Pages, Netlify, Vercel, Cloudflare Pages).
2. Открыть адрес в **Safari** → «Поделиться» → «На экран „Домой“».
3. Приложение запускается без панели браузера и работает офлайн (service worker).

На Android: Chrome → меню → «Установить приложение».

    features.ts            реестр статусов функций (что готово, что на каком этапе)
    projects.ts            список проектов, импорт файла → проект
    useEditorProject.ts    открытие/импорт/сохранение проекта для редакторов

    media.ts               метаданные, превью и кадры шкалы (с учётом Safari iOS)
    storage.ts             мелкие настройки в localStorage
    deliver.ts             сохранение файла: «Поделиться» на iPhone, скачивание, просмотрщик Claude
    useElementSize.ts      размер элемента (ResizeObserver)

  components/

  features/
    home/                  главный экран

      model.ts             монтаж: клипы, музыка, тексты; разрез, обрезка, перестановка, склейка

      usePlayer.ts         воспроизведение монтажа без перекодирования (по <video> на файл)
      audio.ts             громкость через Web Audio (на iPhone media.volume не работает)
      Timeline.tsx         шкала: плейхед по центру, масштаб щипком, ручки обрезки, перетаскивание

        audioMix.ts        сведение звука клипов и музыки (OfflineAudioContext)

        VideoExportSheet.tsx  окно экспорта

      pipeline.ts          параметры правок + попиксельная математика (как CSS-фильтры)
      render.ts            рендер в файл: поворот → обрезка → цвет (Web Worker) → текст
      geometry.ts          рамка обрезки, пропорции, поворот рамки
      PhotoView.tsx        предпросмотр, рамка обрезки, перетаскивание текста
      TextSheet.tsx        редактор надписи
      ExportSheet.tsx      готовое фото и сохранение

    settings/              настройки

Ключевые решения:

- **Без сервера.** Все файлы обрабатываются в браузере и хранятся в IndexedDB на устройстве.
- **Метаданные и медиа раздельно** — список проектов открывается мгновенно, тяжёлый файл читается только при открытии.
- **Правки хранятся параметрами**, а не готовыми пикселями: оригинал не портится, правки можно менять после сохранения.
- **Предпросмотр = результат.** Экспорт повторяет формулы CSS-фильтров попиксельно (проверено: расхождение цвета 0–2 из 255).
- **Ограничение Safari:** холст на iPhone не больше 16,7 Мп, поэтому фото 24/48 Мп при сохранении уменьшаются до этого предела (об этом сообщается). В нативной версии ограничения не будет.
- **Нативные приложения позже** — через Capacitor: тот же код, плюс нативные плагины для галереи и аппаратного кодирования видео.
- **Экспорт без сервера и без ffmpeg.wasm.** WebCodecs кодирует аппаратно; файл собирает свой MP4-сборщик (проверен против ffmpeg: кадры и звук совпадают бит в бит).
  Запасные пути: нет H.264 → VP9; нет AAC → Opus; нет аудиокодировщика (старые iOS) → несжатый звук в MOV.
- **ИИ только через провайдера.** Пока провайдер не зарегистрирован, инструмент показывает «Не подключено» и ничего не имитирует.
