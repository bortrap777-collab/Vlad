# Ws

Мобильный редактор видео и фото. Версия 0.9.0 — плавное воспроизведение нарезки, динамичные переходы, наложения с хромакеем, ключи-отметки, обработка музыки, анимированный текст и субтитры по словам.

## Установить на телефон

Приложение: **https://bortrap777-collab.github.io/Vlad/**

- iPhone: откройте адрес в **Safari** → «Поделиться» → «На экран „Домой“».
- Android: откройте в **Chrome** → меню ⋮ → «Установить приложение» (или кнопка в «Настройки → Установить на телефон»).
- Компьютер: Chrome или Edge → значок установки в адресной строке.

Установленное приложение открывается со своего значка на весь экран и работает без интернета.
Пошаговая инструкция есть в самом приложении: «Настройки → Установить на телефон или ПК».

Обновляется автоматически при каждом изменении ветки `main` (GitHub Actions → Pages).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173 и адрес в локальной сети для телефона
npm run build      # файлы ИИ (scripts/prepare-ai.mjs) + проверка типов + сборка в dist/
npm run preview    # просмотр собранной версии
```

Без доступа к npm (как в облачной песочнице Claude) есть резервная сборка через esbuild:
`node scripts/build-local.mjs` → `dist/`, `node scripts/build-local.mjs --single` → один HTML-файл.
В резервной сборке нет ИИ-инструментов (модель и Web Worker собирает только Vite).

## Установка на iPhone как приложение

1. Выложить папку `dist/` на HTTPS-хостинг (GitHub Pages, Netlify, Vercel, Cloudflare Pages).
2. Открыть адрес в **Safari** → «Поделиться» → «На экран „Домой“».
3. Приложение запускается без панели браузера и работает офлайн (service worker).

На Android: Chrome → меню → «Установить приложение».

Ключевые решения:

- **Без сервера.** Все файлы обрабатываются в браузере и хранятся в IndexedDB на устройстве.
- **Метаданные и медиа раздельно** — список проектов открывается мгновенно, тяжёлый файл читается только при открытии.
- **Правки хранятся параметрами**, а не готовыми пикселями: оригинал не портится, правки можно менять после сохранения.
- **Предпросмотр = результат.** Экспорт повторяет формулы CSS-фильтров попиксельно (проверено: расхождение цвета 0–2 из 255).
- **Ограничение Safari:** холст на iPhone не больше 16,7 Мп, поэтому фото 24/48 Мп при сохранении уменьшаются до этого предела (об этом сообщается). В нативной версии ограничения не будет.
- **Нативные приложения позже** — через Capacitor: тот же код, плюс нативные плагины для галереи и аппаратного кодирования видео.
- **Экспорт без сервера и без ffmpeg.wasm.** WebCodecs кодирует аппаратно; файл собирает свой MP4-сборщик (проверен против ffmpeg: кадры и звук совпадают бит в бит).
  Запасные пути: нет H.264 → VP9; нет AAC → Opus; нет аудиокодировщика (старые iOS) → несжатый звук в MOV.
- **ИИ только через провайдера.** Пока провайдер не зарегистрирован, инструмент показывает «Не подключено» и ничего не имитирует.
- **Удаление фона на устройстве, без сервера.** Модель ISNet (DIS, квантованная, 44 МБ) и движок ONNX Runtime Web (12 МБ)
  лежат рядом с приложением в `ai/` и скачиваются только при первом использовании, затем работают офлайн.
  Источник модели — npm-пакет `@imgly/background-removal-node` (части проверяются по SHA-256 при сборке).
  Расчёт идёт в Web Worker, один поток WASM (на GitHub Pages нет cross-origin isolation для потоков).
- **Фон — тоже параметр правок.** Модель создаёт маску (отдельный файл проекта), а замена фона — композиция при
  предпросмотре и сохранении. Поворот, обрезку, фильтры и вид фона можно менять после, без повторного запуска модели.
  Цветокоррекция действует на всю композицию; прозрачный фон сохраняется в PNG.
- **Слои.** Документ — исходное фото; слои (снизу вверх) рисуются в его координатах, потом поворот, обрезка,
  общая цветокоррекция и надписи. У каждого слоя своя цветокоррекция, прозрачность и маска (ластик/кисть).
  «Объединить» сохраняет картинку слоёв отдельным файлом, а сами слои остаются — «Разъединить» возвращает их.
- **Объекты на устройстве.** Выделение касанием — MobileSAM (энкодер 28 МБ + декодер масок SAM 16,5 МБ, из npm-пакета
  `@geti-ui/smart-tools`, Apache-2.0): фото «изучается» один раз (несколько секунд), каждое касание — доли секунды,
  модель даёт три уровня: деталь, часть, целиком. Удаление — MI-GAN от Picsart AI Research (28 МБ): дорисовывается
  только участок вокруг объекта, остальное фото не пересчитывается. Удаление с фото-основы хранится как
  `stack.photo` — его используют все слои, поэтому удалённое не возвращается ни в вырезанном объекте, ни в фоне.
  Модели скачиваются наборами (`segment`, `select`, `erase`) — каждый инструмент берёт только своё.

## Субтитры (Whisper)

Распознавание речи — своя реализация Whisper поверх ONNX Runtime Web (`src/ai/whisper/`):
лог-мел спектрограмма (совпадает с `WhisperFeatureExtractor` до 3·10⁻⁵), жадное декодирование
с правилами меток времени, окна по 30 с, повтор с «температурой» при зацикливании.
Проверено на записях живой русской речи (Google FLEURS): ошибок по словам 17,5 % (base, q8) и
7,2 % (small, q8); скорость на одном потоке — 2,4× и 0,7× реального времени.
Время каждого слова (0.9.0): после каждого токена смотрим, какую метку времени модель считает
наиболее вероятной, и слова собираются из токенов по пробелу. Если модель не даёт меток внутри фразы,
время делится по длине слов. На реальной записи это ещё не проверено — песочница без доступа к моделям.
Модели скачиваются в GitHub Actions (`scripts/prepare-ai.mjs`, SHA-256 закреплены), файлы
больше 90 МБ публикуются частями.
